# 迁移开发文档

## 工作范围

在 [方法目录](../catalog/methods.json) 中按 R 统计入口跟踪迁移。每条记录包含生物医学分类、优先级、R 入口及许可、Python 候选、待核验的统计行为和官方来源。[迁移进展](../catalog/progress.json) 记录已实施的范围、运行入口、验收证据和剩余任务。单个 R 包的不同统计路径可以分别验收。

| 目录 | 内容 |
| --- | --- |
| `src/biomed_parity/` | 调用时只需要 Python、NumPy 和 SciPy 的统计实现 |
| `catalog/` | 按方法 ID 索引的替代性调研及实施状态 |
| `docs/methods/` | 每个入口的估计目标、数据约定、结果字段、示例及限制 |
| `validation/<方法>/` | 人工构造用例、参考输出、参考生成脚本和可选候选评估 |
| `tests/` | Python 回归、边界条件和本地 R 对照 |

## 实施和验收

1. 明确 estimand、输入假设及输出契约。记录参照组和因子顺序、删失和并列值处理、权重、区间、自由度、缺失值，以及不可估计时的表现。
2. 在同一版本和同一输入上运行现有 Python 候选。区分统计口径、参数默认值、数值算法和纯接口差异。覆盖充分时记录可复用范围，缺失字段有独立价值时补轻量适配或原生实现。
3. 保留 R 参考调用、输入及包版本。值有不确定性的模型用固定重采样索引、闭式特例或分布性质验收。核对中间量与最终区间，防止不同实现碰巧产生相同的 p 值。
4. 保存可脱离 R 运行的参考输出，并提供实时 R 核验。对边界、无信息和截断情形明确记录是返回零、NaN、无穷或错误。数值容差按输出尺度和算法确定。
5. 记录新增实现的来源及上游许可。采用论文和公开接口描述独立实现方法。引用原包作外部参考时记录版本。需要复制或翻译第三方代码时，先核对其授权和衍生要求。
6. 用逻辑独立的 Git 提交保存调研、接口、实现和验证。不提交虚拟环境、临时下载或真实患者数据。验收报告记录本地 Git 版本和运行环境，外部发布另行确定项目许可和维护责任。

## 待扩展工作包

| 竞争风险 | 在边际和反向 Cox 删失评分及固定时点校准之上，验证重拟合交叉验证、自动带宽、同时置信带与成组重抽样。 |
| 试验设计 | 现有边界与条件把握度扩展到伤害停止、事件端点的样本量及日历时间、非恒定疗效和重复置信区间。 |

| 证据综合 | 在已验证的相关抽样协方差、多层随机截距和 CR2 之上，核验随机效应相关结构、预测区间、效应协方差构造和影响诊断。 |
| 抽样与插补 | 复杂抽样继续验证复制权重、孤立 PSU、校准与复杂抽样预测。链式插补继续验证多层条件模型、顺序与无序因子、MNAR、插补块与 D3/D4。 |
| 多状态和联合模型 | 在已验证的长表、转移风险与概率流程上扩展 Markov 检验和转移协变量。联合模型继续验证计数、零膨胀和离散模型的似然、参数尺度及推断。 |
| 人体临床表达分析 | 用公开或人工表达矩阵核对设计矩阵、归一化因子、准似然、经验贝叶斯、混合模型自由度及多重检验。先验证现有实现及版本差异。 |

每个工作包的依据和候选链接见 [调研与优先级](research.md)。
